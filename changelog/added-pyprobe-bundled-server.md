pyprobe-rs now embeds a schema-locked `probe-rs` server binary in the Python extension instead of falling back to whatever `probe-rs` happens to be on `PATH`. The RPC protocol is version-unstable by design, so a system binary could pass a schema handshake yet behave differently (or fail the handshake outright and trigger repeated heal restarts). The manager now resolves `PYPROBE_RS_BIN` → the embedded binary → the workspace build, and never consults `PATH`; the embedded copy is materialized once into the per-user runtime directory with the executable bit set.
